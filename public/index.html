A web server written in Node.js and Express

This page is a plain HTML file delivered by an Express server using express.static().

$ npm install
$ npm start
Server is running on http://localhost:3000

Static Files

HTML, CSS and images are served straight from the public folder.

Clean Routes

/about and /contact are mapped to HTML files with res.sendFile().

JSON API

/api/status returns live server information as JSON.
